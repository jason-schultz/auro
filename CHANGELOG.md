# Changelog

Newest first. Each version collects the changes since the last release; the one marked
TBD hasn't been released yet. Each line is one change with a link to its commit.

Releases start once Auro runs locally as a service; until then everything is in 0.1.0.

## Version 0.1.0 (TBD)

- Seven new strategy blocks: Bollinger bands, Stochastic, Trend strength (ADX), Calm or wild (bar size vs usual), Day's average price (VWAP), Opening range and Pivot points. (commit pending)
- Blocks explain themselves: each says in one sentence what it watches, every setting has a hint ("Lower means fewer, more extreme dips count"), and the "Add a block" list is grouped by the question it answers (Trend, Stretch, Breakout, Momentum, Volatility, Levels). (commit pending)
- The strategy preview draws the indicators themselves: averages, bands and levels on the candles, and RSI, MACD, stochastic and the like in small panels underneath with their threshold lines, so changing a setting shows what it does. (commit pending)
- Four example strategies to start from in the builder: buy dips in an uptrend, ride a breakout, follow the trend, and an intraday breakout. (commit pending)
- New York session hours (09:30–16:00, early closes) shared by every block that needs them, instead of living inside the noise band. (commit pending)
- README rewritten for what Auro is today; this changelog started. (commit pending)
- Strategies are now recipes (the rules) assigned to instruments (where they run, at what size): one RSI(2) dip-buy recipe runs on SPX500, NAS100 and EU50. ([afcccef](https://github.com/jason-schultz/auro/commit/afcccef397f76dd8bfa02f45bab0d7e3d98ab80a))
